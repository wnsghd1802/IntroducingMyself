# BR-A · 독립 자기소개 웹사이트

기존 `https://kjhnet.vercel.app` 포트폴리오를 수정하지 않고, **같은 다크 네이비·블루 네트워크 디자인 언어를 사용하는 별도 웹사이트**로 새로 만든 정적 사이트입니다.

## 구성
- `index.html`: 자기소개 / 1인칭 3분 자기소개 전문 / 3가지 역량 근거 / 13주 과정 리추얼 집계 / 10번 논문과 13번 앱 / 문서 다운로드
- `research.html`: 10번 연구 내용 및 한계
- `app.html`: 13번 분석 앱의 계획 및 진행 상태
- `assets/`: UI 스타일, 반응형, 네트워크 SVG, 스크롤 및 자기소개 펼치기 동작
- `documents/`: 공개용 이력서·자기소개서·경력기술서 PDF / DOCX
- `data/site-data.json`: 기존 공개용 숫자 및 출처 메타데이터 스냅샷
- `scripts/update_metrics.py`: 새로 확보한 **비식별 CSV**에서 후보 집계 파일 생성(승인 전 자동 게시하지 않음)

## 실행
`python -m http.server 8000` 실행 후 `http://localhost:8000`을 열면 됩니다. 외부 라이브러리나 API 키 없이 동작합니다.

## 별도 배포
새 GitHub 저장소를 만들고 **이 폴더 내용만** 업로드해 새로운 Vercel 프로젝트에 연결하세요. 기존 `kjhnet.vercel.app` 프로젝트를 덮어쓰지 마세요.

## 수치·출처 안내
- 2026.08.11~10.21 리추얼 자기평가 기록이 있는 날짜 44일, 기록 있는 ISO 주 11개, 실천 18일 / 일부 20일 / 미실천 6일은 이전 BR-A 검수 자료에 남은 공개 집계입니다.
- 이 44일은 교육 출석일수도, 출석률도, 과제 합격률도 아닙니다.
- 해당 44일의 비식별 원시 CSV는 제공받지 않아 사이트에는 집계 스냅샷만 두었습니다. `update_metrics.py`로 기존 44일을 재계산할 수 있다고 주장하지 않습니다. CSV 확보 후 후보를 계산해 검수하고, HTML 및 JSON을 동기화해야 합니다.
- 연구의 공개 채팅 탐색적 분류 F1 값은 특정 플레이어의 의도적 방해 탐지율을 의미하지 않습니다.
- 2026.11.03 기준 17경기·의심 2건은 **사용자 관찰 보고**이며 영상 독립 검증을 완료한 값이 아닙니다.
- 앱 개발 단계의 기능은 구현 완료로 기재하지 않습니다.

## 공개 범위와 수정 사항
고객사·회사명·개인 연락처·기기 주소·비밀정보를 포함하지 않았습니다. 2026.11.04 공개용 요약본 문서는 취업 지원 회사별 최종 제출 전 검토가 필요합니다. 기존 포트폴리오·GitHub 연결은 열어 두었으나 로그인과 원본 논문 PDF를 요구하지 않습니다.

## 역할 구분
AI가 웹 코드, 편집·서식, 문서 초안 생성을 보조했습니다. 실제 경험·경력의 표현, 근거 수치의 출처와 한계, 공개 여부는 사용자가 결정한 내용을 따랐습니다.

## 2026-11-05 개선
- 메인 페이지의 문서 카드는 다운로드 대신 `resume.html`, `cover-letter.html`, `experience.html` 상세 화면으로 연결합니다.
- `resume.html`에서 사진과 경력·학력·교육·자격을 HTML로 확인할 수 있습니다. 첨부받은 원본 PDF는 별도로 여백을 정리했으며, 공개 웹사이트에는 상세 개인정보가 있는 원본 파일을 올리지 않았습니다.
- 기존 자기소개서와 경력기술서 PDF는 상세 페이지의 부가 링크로 옮겼습니다. 공개 화면의 AI 작성 과정 설명을 삭제했습니다.
- `vercel.json`은 동일 출처 내 PDF 미리보기가 필요할 경우를 대비해 설정했습니다.
